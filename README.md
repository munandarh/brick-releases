# Brick downloads

Installer releases will appear here after the native build checks complete.

Download Brick from [the latest release](https://github.com/munandarh/brick-releases/releases/latest).

- **macOS Apple Silicon:** download `Brick-arm64.dmg`, open it, and drag Brick to Applications.
- **Windows x64:** download and run `Brick-Setup.exe`. It installs for your current user.
- `Brick-darwin-arm64.zip` is retained for existing macOS in-app updates.
- `SHA256SUMS.txt` contains download checksums.

These builds are not Apple Developer ID signed/notarized or Windows Authenticode signed, so your operating system may show trust warnings.

This repository distributes installers. The application source remains private. GitHub's automatic source archives contain this download repository, not the application source.
